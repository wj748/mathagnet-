## 板块缺口补齐：模板生成题（方案「每板块 ≥200 题」达标）
**根因分析**（重要，避免重复踩坑）：
- TAL-SCQ5K 5000 条里按 `competition_source_list` 统计只有 **992 条是初中**，
  其余 2905 条小学、1103 条无标注（多为高中）。初中桶里几何仅 126 条 → 该源天花板就是 126。
- 备选源 `cn-k12` 采样验证为 **99.8% 英文且偏高中**，不可用（已放弃）。
- 结论：**靠换数据源补不满，改用模板生成**。

**方案**：`scripts/gen_geometry_questions.py` → `data/processed/synth_questions.jsonl`
（parsed 中间格式，由 `build_question_bank.py::load_synthetic()` 合并入库）。
- **39 个模板**：几何 21 + 方程 10 + 函数 8。模板函数用**函数属性**声明板块：
  `_t.topic = "二元一次方程"` / `"函数"`，`_t.is_app = True`；`build_question` 读
  `getattr(tpl,"topic","几何图像")`，source 标记 GEO_TEMPLATE / ALG_TEMPLATE。
- 答案由程序计算；干扰项来自典型错法；解析是真实分步推导。
- 参数随机前先校验「干扰项互不重复且 ≠ 正确答案」，不够时用数值扰动兜底 → 模板不会静默丢失。
- question_id 前缀 `GEO_`，与 TAL 区分。

**踩过的坑**：
1. `t_isosceles_apex` 第三个干扰项 `90-apex/2` 恒等于正确答案（底角）→ 必须手算验证。
2. `t_circle_area` 干扰项写成了答案本身；`t_sector_area` 0.75 被四舍五入成 0.8；`t_similar` 除不尽。
3. **系数排版**：f-string 里 `y={k}x{b}` 会产出 `y=-1x`、`y=1x+5`。必须封装
   `_coef(k, sym)` / `_kx(k)` / `_lin(k, b)`。注意 `_coef` 已自带变量名，
   后面**不能再拼 `x`/`y`**（曾产生 `3xy`）。y 的系数用 `_coef(b,'y')`。

**超纲过滤强化**（`HIGH_SCHOOL` 正则）：原规则漏掉大量高中题，实测函数板块出现
反函数、等比数列、Σ 求和、log。补充：反函数|等比数列|Σ/`\sum`|log_/ln|单调区间|值域为|
复合函数|抽象函数|递推公式|通项公式|方差|柯西|均值不等式|求导|切线方程 等。
→ 额外过滤 82 条，**零误伤**（已用旧规则对比验证）。

**最终规模**：2082 条（TAL 清洗去重 569 + 模板 373）。
函数 259 / 二元一次方程 253 / 几何图像 266 / 综合 164 —— 三大板块全部 ≥200。
验收：34/34 + 7/7 + 7 passed 全绿。
